Welcome to Lumen.

Your apps. Your workflow. Your space.

Lumen is an application launcher and usage tracker for Linux, written in C++. Its goal is to combine a fast, customizable launcher with application usage tracking, session statistics and a modern graphical interface.

⚠
Early stage of development

Lumen currently includes a CLI prototype, a graphical interface and application usage tracking. Some planned features are not implemented yet.

Explore Lumen

Why Lumen?

Lumen started as a small C++ project for learning Linux internals, application management and desktop environment integration. The long-term goal is to grow from a simple launcher into a fully featured desktop activity panel.
